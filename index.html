Industrial monitoring and reporting

The tasks of collecting, archiving, and visualizing production data exist in factories of all sizes and industries: from basic electricity consumption accounting, already provided to some extent by existing AMR systems, to evaluating the efficiency of production facilities (OEE). Even office centres and shopping malls need regular monitoring of resource consumption. There is also a need to monitor the health of equipment and the computer networks that transmit data to servers. To address these challenges, we use open-source software and modern approaches.

For typical monitoring tasks, such as tracking electricity consumption, temperature, and humidity, we will be happy to advise you and help select and install the necessary equipment.

Project description

SmartObject is a Zenon technology that makes implemented objects easy to reuse, much like classes in traditional programming. A SmartObject can include tags, screens, screen templates, functions, logic, and other project components.

When a SmartObject instance is added to a project, its variables, functions, screens, and other components are created and numbered automatically, saving development time. Changes such as adding tags are then automatically updated across all instances in the project.

The SmartObject for Huawei SUN2000 series inverters provides the core functions needed for diagnostics and control:

  • •Overview screen with inverter current, voltage, frequency, and meter readings.
  • •DC input status, including voltage and current.
  • •Power indicator screen with a graph.
  • •Inverter status details: temperature, insulation resistance, efficiency, operating mode, and error codes.
  • •Error register decoding with status indication.
  • •Settings and control screen.

Project description

The dispatching system for geographically distributed solar power plants is built on the Zenon SCADA platform.

Industrial monitoring · OEE

Equipment utilization (OEE)

Project parameters

Number of measurement points
> 15
Electrical network analyzers
Socomec DIRIS A10 Socomec DIRIS A20
Network equipment
MikroTik KNOT
Software and tools
Ubuntu Linux Zabbix Grafana Python

Project description

Equipment utilization monitoring for production machinery such as CNC machines, presses, and paint booths is implemented by measuring electrical current and determining the operating mode from its magnitude.

Each measurement point can be in one of three modes: off, idle, or operational. Analysis of current values from the network analyzers identifies downtime and operating periods across a shift, day, or week. Results appear on clear dashboards and update in real time.

In OEE (Overall Equipment Effectiveness) terminology, the system calculates the availability criterion, a fundamental input for further OEE calculations. Availability depends on different types of downtime, including breakdowns and failures, lack of raw materials, or lack of operator attention.

Advantages

  • •Automatic operating mode detection eliminates the human factor and requires no operator action.
  • •No intervention in the machine’s electrical circuit is needed.
  • •Integrates with ammeters, electricity meters, and network analyzers equipped with a digital output.

Monitoring the power supply of a production site with multiple sources and end-users

Project parameters

Number of measurement points
> 10
Electrical network analyzers
Socomec DIRIS A20 Socomec Digiware
Network equipment
MikroTik KNOT
Software and tools
Ubuntu Linux TimescaleDB Grafana Python

System configuration

The monitoring system covers a production site supplied by multiple sources and serving multiple end-users. The electrical equipment includes:

  • •Low-voltage input from the substation.
  • •Genset.
  • •Photovoltaic power plant.
  • •Automatic transfer switch (ATS).
  • •End-user measurement points.

The substation, genset, and photovoltaic plant inputs are monitored by Socomec DIRIS A20 network analyzers with RS485 communication modules using Modbus RTU. The ATS controller connects through a MikroTik KNOT Modbus RTU/TCP gateway. End-user metering points are monitored by the Socomec Digiware system.

Python scripts write parameter values directly to a database hosted on a separate virtual machine.

Parameters collected at each measurement point

  • •Phase-to-neutral voltages.
  • •Phase-to-phase voltages.
  • •Phase currents.
  • •Per-phase active and reactive power.
  • •Average voltage and current.
  • •Total active, reactive, and apparent power.
  • •Total harmonic distortion (THD) for voltage and current.
  • •Power factor, averaged and by phase.
  • •Import and export energy counters for active, reactive, and apparent energy.
  • •Connection quality.

ATS parameters saved to the database

  • •Operating mode.
  • •Status code.
  • •Error code.
  • •Voltage on both inputs.
  • •I/O state.

Grafana dashboards

  • •Current electrical parameters for end-users.
  • •Current ATS and genset parameters.
  • •Trends and historian.
  • •Power consumption report for each measurement point.

Software and tools

System configuration

The monitoring system supervises the power supply of a medium-sized factory. It consists of a low-voltage source input measurement point and five power distribution panels (PDPs) distributed across the site.

Each measurement point uses a Socomec DIRIS A20 with an RS485 communication module (Modbus RTU). A MikroTik KNOT gateway connects the analyzers using Modbus RTU/TCP.

Python scripts send parameter values to Zabbix and store them in a database hosted on a separate virtual machine.

Parameters collected at each measurement point

  • •Phase-to-neutral voltages.
  • •Phase-to-phase voltages.
  • •Phase currents.
  • •Per-phase active and reactive power.
  • •Average voltage and current.
  • •Total active, reactive, and apparent power.
  • •Total harmonic distortion (THD) for voltage and current.
  • •Power factor, averaged and by phase.
  • •Import and export energy counters for active, reactive, and apparent energy.
  • •Connection quality.

If measurements exceed defined limits, Zabbix can send alerts by email, SMS, or messenger.

Grafana dashboards

  • •Power by measurement point and total power.
  • •Current values for every measurement point.
  • •Trends and historian.
  • •Power consumption report for each measurement point.
